# Submission Checklist

## Functional application

- [ ] At least five scenario products show names and Philippine-peso prices.
- [ ] Add, increase, decrease, and remove controls work.
- [ ] Cart subtotals and total recalculate correctly.
- [ ] Blank, non-numeric, negative, and insufficient payments show clear errors.
- [ ] A sufficient payment shows correct change and confirmation.
- [ ] Receipt includes items, quantities, subtotals, total, paid amount, change, and transaction reference.
- [ ] New transaction clears all previous transaction data.

## Evidence

- [ ] Screenshot: product list/order screen.
- [ ] Screenshot: cart/order summary.
- [ ] Screenshot: successful payment and computed change.
- [ ] Screenshot: receipt.
- [ ] Screenshot: GitHub commit history with messages and timestamps.
- [ ] Two or more accurate AI Prompt Records are complete.

## GitHub milestones

- [ ] Repository created and pushed.
- [ ] Initial commit: project setup and basic interface.
- [ ] Core commit: ordering, totals, and change computation.
- [ ] Final commit: validation, debugging, and improvements.
- [ ] README or short project documentation describes the application.

## Final review

- [ ] One full transaction has been tested from browse through receipt and new transaction.
- [ ] Required evidence and repository link are ready.
- [ ] The student can explain the main functions and any AI-assisted code.
