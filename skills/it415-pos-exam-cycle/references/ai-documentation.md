# AI Development Documentation

The documentation form requires at least two separate AI prompt records from different points in development. Fill it out during work, not only at the end.

## One record per meaningful interaction

For each selected prompt, record:

| Field | Record |
| --- | --- |
| Prompt used | Exact text sent to the AI assistant. |
| Purpose | What the prompt was intended to accomplish. |
| AI response | Brief accurate summary, or an actual response screenshot. |
| Evaluation | Correct, partially correct, or incorrect, with why. |
| Modifications | Corrections or adjustments made before use. |
| Verification | Tests actually run and their result. |

Good minimum coverage is one prompt for a feature (for example, cart totals or receipt creation) and one for debugging, validation, or refactoring. Keep enough detail to explain the resulting code during checking.

## Honest-record rule

Only document AI interactions that actually occurred. If the response needed correction, say so plainly. A concise truthful evaluation is stronger evidence than a generic claim that the response was correct.
